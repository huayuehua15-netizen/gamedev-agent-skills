## 3. 贴图规范

- PBR：金属/粗糙度工作流；通道打包：【ORM：R=AO G=Roughness B=Metallic / 其他】
- 法线方向：【Unity OpenGL / Unreal DirectX】
- Texel density：1024px/m（近景 2048px/m）；最小缝隙 ≥4px
- 静态场景资产必须有第二套不重叠 lightmap UV
- 粗糙度/金属度参考：裸露金属 0.2-0.6、锈蚀 0.7-0.9；木材 0.5-0.8；积灰 +0.1

## 4. LOD

- ≥3 级；屏幕占比阈值：LOD1 【】%、LOD2 【】%；远处 impostor
- 切换不得可见跳变（屏幕测试）

## 5. 碰撞

- 简化碰撞命名 `UCX_名称_01`；门/抽屉按可动部件拆并设枢轴
- 纯装饰小物标记不碰撞

## 6. 命名

- 网格 `SM_类别_名称_序号`；骨骼 `SK_`；贴图 `T_名称_BC/N/RMA_1024`；材质 `M_`/`MI_`
- 模块件：`SM_Wall_400x300_A`；引擎目录 `Art/Props/区域/资产名/`

## 7. 导出与导入（{{ENGINE}}）

- 格式：【FBX/glTF】；单位：【】；轴向：【】；缩放因子 1
- 导入设置：静态/动态【】、Lightmap UV【】、纹理压缩【PC:BCn / Deck:ASTC】、mipmap 开、Read/Write 关、Instancing 标记
