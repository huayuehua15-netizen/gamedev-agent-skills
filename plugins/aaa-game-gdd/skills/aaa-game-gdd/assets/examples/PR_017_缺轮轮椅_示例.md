# 道具/资产单页：缺轮轮椅

- 编号：PR_017　所属：霜脊隘口
- 关联：08 建模规格、02 美术圣经、03 场景、06 交互、09 动画、10 音频、11 性能

> 本文是**道具范文**。道具文档最容易漏的是"它为什么长这样"和"它的成本边界在哪"。
> 这份重点在 §2 叙事与玩法的绑定、§5 技术规格的完整取值、以及 §7 DoD 里可打勾的实测项。

## 1. 基本信息

| 项 | 内容 |
|---|---|
| 类别 | 场景道具（叙事型，轻交互） |
| 出现场景 | SC_01（走廊 4m 处）、SC_03（病房 2 具） |
| 数量与复用 | 共 3 具，同一模型；仅旋转与贴花变体不同 |
| 可交互 | 推动（可移 1.2m，产生噪声） |
| 视角 | 近景（玩家 1-3m 可观察细节） |
| 叙事含义 | 撤离时的仓促——缺的那只轮子不是损坏，是被拆走当担架支腿（对应 SC_01 叙事道具清单） |

## 2. 需求描述

- 玩家会对它做什么：推开（清理通路或制造噪声引开敌人）；也可能只是路过扫一眼
- 交互反馈：
  - 确认：准星变化 + 「推动」提示
  - 过程：轮子滚动声（只有一侧有轮，因此声音是"咯—嗒—咯—嗒"的不均匀节奏）
  - 结果：位移 1.2m 后停下，制造 14m 噪声半径（与 SYS_02 噪声系统一致）

> **一个刻意的设计**：只有一侧有轮，所以推动时**必须斜着走**（另一侧拖地）。
> 这让它无法被用来"刷"位移，也让声音天然不均匀——叙事（缺轮）与玩法（噪声）由同一个特征承担。

## 3. 参考与概念

- 真实照片参考：1990s 医院折叠轮椅（钢管+帆布座）；影视/游戏参考：《寂静岭》系列病房陈设
- 学什么：钢管的口径与连接方式、帆布座的松弛下垂、脚踏板的折叠结构
- 概念图需求：3/4 视角 1 张、**缺轮侧的近距离细节 1 张**（这是叙事的落点，不能省）、做旧程度=重度（血渍 2 层 + 铁锈 1 层 + 灰）

## 4. 尺寸

- 真实尺寸：展开 64cm（宽）× 105cm（深）× 92cm（高）；**是否夸张比例：否**（写实项目，尺寸必须可核对）
- 参照校验：与 1.70m 人体标尺并排放置，座椅面高应为 0.50m（坐下时膝弯高度）

## 6. 动画/特效/音效需求

- 动作：推动位移由刚体+脚本实现，**不做动画**（1.2m 位移用物理即可，省一个动画）
- 破碎/破坏：不可破坏（叙事道具，破坏会丢失信息）
- 挂点特效：推动时地面扬尘（复用 VFX_Dust_Small）
- 音效：交互 AU_Prop_WheelchairRoll（循环，随速度调音高）；推动停止 AU_Prop_WheelchairStop
