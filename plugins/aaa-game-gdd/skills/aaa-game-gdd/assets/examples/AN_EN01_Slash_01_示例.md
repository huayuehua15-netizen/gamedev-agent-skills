# 动画单页：缝合者·挥砍

- 编号：AN_EN01_Slash_01　所属：霜脊隘口
- 关联：04 玩法帧数据、06 交互、07 角色、09 动画规格、10 音频

> 本文是**动画范文**。动画文档最常见的失败是"写了描述、没写帧"，导致程序无从实现判定、
> 动画师无从对齐节奏。所以这份的核心是 §2 三段式帧区间与 §3 事件埋点必须逐帧可执行。

## 1. 基本信息

| 项 | 内容 |
|---|---|
| 角色 | EN_01 缝合者 |
| 状态机位置 | Chase → Attack → Chase |
| 类型 | 攻击 |
| 目的 | 缝合者的主力伤害手段；它的可读性决定整场战斗是否公平 |
| 循环 | 单次 |
| 总时长 | 42 帧 = 0.70 秒 @60fps |
| 根运动 | 否（原地挥砍；位移由 AI 的 Chase 负责） |

## 2. 三段式帧区间（与 04 战斗表逐帧一致）

| 阶段 | 帧区间 | 秒 | 关键姿态 |
|---|---|---|---|
| 预备 Anticipation | f0 - f11 | 0.183s | 右臂抬至耳侧，身体向左侧倾 12°，头部微微歪向猎物（预告） |
| 发生 Action（判定窗口） | f12 - f20 | 0.150s | 从耳侧横扫至左前下方；判定盒在 f13 开启 |
| 余响 Follow-through | f21 - f34 | 0.233s | 挥空后惯性带身体转 25°，手臂下沉到膝侧 |
| 可取消窗口 | f35 - f41 | 0.117s | 可接下一次攻击或回到 Chase |
| 过渡时长 | 进入 0.10s / 退出 0.15s | | 从 Chase 混入；退出接 Chase |

> **可读性预算**：从"抬臂开始"到"判定命中"共 13 帧 = **0.217s**。
> 人类对单一动作的视觉反应时间约 0.25s，加上这是**预告动作**（不是突然出现），
> 0.217s 偏紧但对可格挡/可后退的玩家是可反应的。若测试发现躲不开，**优先延长预备段而不是缩短判定**——
> 缩短判定会让"看起来打到了却没伤害"，比打不中更伤。

## 3. 动画事件（逐帧埋点）

| 帧 | 事件 | 参数 |
|---|---|---|
| f0 | PlayWhoosh（起手风声） | AU_EN01_Slash_Wind，音量 0.6 |
| f11 | **预告音（核心线索）** | AU_EN01_Slash_Telegraph，0.5s，无音高变化 |
| f13 | HitboxOn | 判定盒 = 前方 2.6m 扇形 110°，伤害 22，韧性削 20 |
| f13 | CamShake（仅在命中时） | 幅度 0.15，时长 0.12s |
| f15 | HitStop（仅命中时） | 4 帧（0.067s） |
| f17 | HitboxOff | — |
| f20 | 刀风收尾 | AU_EN01_Slash_End |
| f27 | FootstepL | surface = 由当前地面材质决定（瓷砖/木板/湿地） |
| f34 | 状态回 Chase（可取消窗口结束） | — |

> 注意 f11 的预告音：这是**给玩家的唯一公平线索**。所有攻击性敌人动作都必须在判定前
> 有一个明确的事件埋点，否则玩家只能靠背板。该音效在混音中优先级高于环境声，-8dB。

## 4. 移动与融合

- 周期位移（循环移动）：不适用（单次攻击，无根运动位移）
- 与代码速度匹配：AI 在攻击期间将移动速度降为 **0.4 m/s**（正常追击 3.4），避免"边冲边砍"的廉价感；该减速由 AI 侧实现，动画本身不含位移
- Blendspace 轴：不适用
- 上半身叠加 / 覆盖层：受击动画用上半身叠加层（AN_EN01_Hit_L），保证被打断时下半身仍在走

## 5. 表演（对话/过场时）

- 面部表情：不适用（面部被绷带遮挡 60%，仅眼睛可见）；表演靠**头部倾斜幅度**——倾听时歪 25°
- look-at 目标：无（它不看玩家的眼睛，看玩家的躯干，强化"在评估材料"的观感）
- 手势/重心：不适用（本动画非表演）
- 口型：无台词

## 6. 2D 帧动画（若为序列帧）

不适用（3D 角色）。若未来做 2D 版本，此节按 09 §二 的帧率分层（12/15/24fps）填写，
其中 42 帧 @60fps ≈ 21 帧 @30fps；但**判定窗口必须保持 0.15s**，即 30fps 下改为 f7-f11。
