# 12 3A 质量门禁、QA 与 Steam 上架验收

## 解决什么问题

给出「达到什么标准才能发」的唯一权威清单：阶段门禁、QA 测试矩阵、Bug 分级、3A 十维评分、Steam 商店资产与 SDK 特性、Steam Deck 验证、本地化与上架流程。**所有具体尺寸/规格上传前以 Steamworks 官方文档当前版本为准**（Valve 会更新）。

## 一、阶段门禁明细

| 门禁 | 准入内容 | 必须通过 |
|---|---|---|
| 垂直切片 | 10-15 分钟最终品质流程 | 核心循环可玩；帧预算实测达标；美术/动画/音频管线全走通；存档/输入/设置可用；新人照单页能独立做资产 |
| Alpha (Feature Complete) | 全部系统功能完成 | 可从头通关；无占位 UI/系统；全输入设备可用；性能持续达标 |
| Beta (Content Complete) | 全部美术/音频/文本/本地化完成 | 零 S/A bug；通关全流程×3 配置档；成就/Cloud 验证；Deck 兼容性验证 |
| RC（候选发行） | 最终构建 | 商店页审核通过；发行渠道包验证；回滚预案；Day1 patch 流程 |

## 二、QA 计划与 Bug 分级

### Bug 分级

- **S（阻断）**：崩溃/存档损坏/流程卡死/无法启动/数据丢失。**RC 必须为 0**。
- **A（严重）**：核心功能失效、成就不触发、严重性能问题、无简单绕过。**RC 必须为 0**。
- **B（一般）**：功能受损但有绕过、轻微穿模、偶发判定错误。规定数量上限（如 ≤20）。
- **C（轻微）**：文字、音效、视觉小瑕疵。可带限量发行但需记录。

### 测试矩阵（逐格写结果与责任人）

- **配置**：最低/推荐 PC、核显、Steam Deck（Win/SteamOS）、Win10/11；分辨率（1080/1440/4K/21:9）。
- **输入**：键鼠、Xbox/PS/Deck 手柄、重映射、UI 全流程无鼠标死角。
- **流程**：黄金路径通关、全成就解锁、全结局/分支、每种死亡与失败、暂停/读档/过场打断组合。
- **边界**：Alt+Tab、断网、磁盘满、旧存档迁移、多语言切换、手柄中途断连、挂起恢复（Deck）。
- **兼容**：Cloud 存档跨设备、无中文路径问题（安装路径/用户名）、杀毒软件误报、超宽屏。
- **自动化**：每日构建冒烟（启动→主菜单→试玩 5 分钟）；崩溃率监控（目标 <0.1% 会话、零必现崩溃）。

## 三、3A 十维评分表（审校/门禁通用）

逐维 1-10 分，每分必须附证据（文档/截图/实测数据），无证据不打分。

| 维度 | 看什么（证据） | 合格线 |
|---|---|---|
| 1 视觉表现 | 美术圣经执行度、画面统一、材质/光照/后处理 | ≥7 |
| 2 动画与表演 | locomotion、动作三段式、面部口型、过场、无滑步 | ≥7 |
| 3 游戏手感 | 100ms 反馈、输入缓冲、hitstop/震屏/震动、无无效操作 | ≥7 |
| 4 叙事与角色 | 故事、节奏、台词质量、弧光、信息增量 | ≥7 |
| 5 音频音乐 | 音乐体系、脚步/环境变体、混音、对白清晰、定位 | ≥7 |
| 6 UI/UX | 3 次操作进游戏、HUD、菜单、设置完整度、可访问性 | ≥7 |
| 7 关卡设计 | 动线、节奏曲线、引导、遭遇策略、防迷路 | ≥7 |
| 8 系统深度 | 核心循环、数值平衡、资源 Source/Sink、边界处理 | ≥7 |
| 9 技术性能与稳定 | 帧时间、加载、崩溃、兼容、存档 | ≥7（本维不得低于 7） |
| 10 打磨与细节 | 边界情况、世界反应度、文本/图标/音效无遗漏、隐藏内容 | ≥7 |

评级：**任一维 <6 不予立项发售；总分均 ≥7 为独立 3A 品质合格；核心支柱相关维度 ≥8 才算「对标 3A」**。评分后输出：硬伤清单（必须修）、体验减分项（应该修）、锦上添花（可延后）。

### 2. 商店文本与信息

- 短描述、详细描述（支持 BBCode/图片，结构：钩子→特性 bullet→世界观→媒体引用位）、游戏标签、系统需求（最低/推荐，含真实测试数据）。
- 内容问卷（Steam 自家的 Content Survey，**不是 IARC**——IARC 是 Google Play/任天堂/微软那套）：如实填写暴力/血腥/恐怖/成人元素，Valve 据此生成各地区分级。德国需要 USK、巴西需要 ClassInd，这两地漏填等于漏掉两块市场；隐瞒内容会被下架。
- 隐私政策（有任何联网/遥测/账号功能时必需）、EULA（如需要）。
- 本地化支持矩阵三列：界面 / 完整音频 / 字幕，逐语种勾选，**卖什么语言写什么语言，不达标不勾选**。
- 客服邮箱、官网/社区链接。

### 3. Steamworks 功能集成（逐项确认是否做）

- 成就（图标已上传、解锁条件与文案本地化、全部实测可触发）。
- Steam Cloud（存档路径配置、跨设备实测）。
- 富文本状态 Rich Presence、排行榜（如有）、集换式卡牌（满足资格后）、创意工坊（可选）。
- 控制器配置（Steam Input，Deck 验证基础）。
- 遥测/崩溃上报（隐私政策声明）。
- 离线模式可玩、家庭共享/家庭组兼容。

### 4. Steam Deck 验证（Verified 四标准）

1. **输入**：完整控制器支持，无必须键鼠/触屏的操作，控制器图标正确。
2. **显示**：Steam Deck 原生分辨率运行，文字可读（1280×800 下 HUD/字幕）。
3. **无缝**：默认设置流畅、无兼容性警告、挂起/恢复正常。
4. **系统支持**：Proton/音频/所有功能正常。
未达标的游戏只能是 Playable/Unsupported，直接影响 Deck 用户转化。

### 5. 构建与发行流程

- **时间线上的三个硬门禁（漏掉任何一个都会直接推迟发售）**：
  1. **付完 App 费用后有 30 天等待期**才能正式发售——不是"提交后 30 天"，是从付款起算。别等到准备发版了才注册。
  2. **商店页审核约需 7 个工作日**（Valve 官方口径），不是"数个工作日"，排期按 ≥7 个工作日留。
  3. **税务与收款流程（W-8BEN 等）**：非美国开发者必填，审核也会花时间，且没有它收不到款。
- App 费用为 **100 美元/款**（可回收门槛，非订阅），预算里要写。
- Depots 分区（按需）、默认分支、测试分支；至少 2 周上架「即将推出」页（收集愿望单）。
- 发行前提交构建审核；私有测试分支走完整下载安装流程；Demo（强烈建议，配合 Next Fest 节点）。
- 定价与区域定价、首发折扣策略、捆绑包（如有）、评测码发放流程。
- Day1：补丁分支与热修流程、回滚版本、上线当天监控值守表、社区公告/首日补丁说明。

- [ ] 全部商店资产与文本按最新官方规格上传，内容问卷如实填写
- [ ] 成就/Cloud/控制器/离线模式实测；Deck 验证通过（或明确标注兼容状态）
- [ ] 本地化矩阵与实际一致，字幕/字体/文本膨胀全部验收
- [ ] 商店页审核通过、构建审核通过、定价与隐私政策就绪
- [ ] 热修与回滚预案、首日值守表就位
