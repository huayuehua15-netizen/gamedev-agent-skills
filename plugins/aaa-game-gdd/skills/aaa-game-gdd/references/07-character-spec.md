# 07 角色规格（主角 / 敌人 / NPC）

## 解决什么问题

把一个角色从「文字设定」变成美术、动画、音频、AI 程序都能直接开工的规格单。每个角色一张 character-sheet（敌人/怪物同样使用，编号前缀不同）。

## 何时写

垂直切片期做主角 + 1 个核心敌人 + 1 个 NPC 样板；量产前完成全部角色。角色必须与 05 剧情弧光、04 系统数值、08 建模规范、09 动画规范对齐。

## 角色单页章节

### 1. 基本信息

编号与命名（`CH_`主角 / `EN_`敌人 / `NPC_`）、首次出场关卡、出场频率、戏份权重、是否可被击杀/是否反复出现。

### 2. 角色定位（一句话）

- 在故事中的功能（引导者/压迫者/镜像/牺牲者）；在玩法中的功能（教学/追击/消耗/补给/解谜）。
- 玩家见到他时**应有的情绪**，以及该情绪由哪些手段保证（外形/声音/行为/镜头）。

### 3. 背景与性格（供编剧与配音）

- 欲望/需求/谎言/弧光（引用 05）；说话方式（口头禅、语速、用词阶层）、与其他角色的关系。
- 写作纪律：性格必须通过**可表演行为**落地，例如「紧张时反复擦听诊器」，而非只写形容词。

### 4. 外观设定（美术需求）

- 年龄/体型/身高（cm）/头身比；服装（年代、层次、破损程度、污渍）、随身物品、标志物。
- 形状语言与剪影：用方/圆/三角的设计说明，剪影必须可辨认（引用 02 美术圣经）。
- 色彩：主色/辅色/点缀（与美术圣经色板一致），在场景中的跳出策略（危险角色如何被一眼识别）。
- 概念图需求：正面/侧面/背面三视图、头部细节、服装细节、关键道具、表情包（至少 6 种核心表情）。
- 怪物专用：恐怖来源分类（未知/畸变/拟人崩坏/不可名状）；露出管理——每章正面可见时长、先露声音/痕迹还是本体、残肢/演出尺度（与 Steam 分级问卷挂钩）。

### 5. 建模与贴图规格（引用 08，给本角色的具体数值）

| 项目 | 数值 |
|---|---|
| LOD0 三角面预算 | 主角 60k-100k；重要敌人 40k-80k；普通 NPC 15k-40k（行业参考值，按 11 预算调整） |
| 骨骼数 | 主角 150-250；NPC 100-200 |
| 贴图尺寸 | 主角 4096²（身体/头/服装可拆分）；NPC 2048² |
| 材质 | PBR，通道打包方式见 08 |
| LOD | 至少 3 级（100%/50%/25%），远距离 impostor |
| 表情 | 面部 blendshape 数（写实 ≥52 ARKit；风格化 ≥20） |

### 6. 动作集（引用 09，逐条列动画需求）

-  locomotion：站立/走/跑/蹲/跳/转身/落地（含 8 方向或 blendtree 要求）。
-  动作：攻击/受击/死亡/交互/特殊动作（每个给行为目的）。
-  过场/表演动作：引用对话与过场编号。
-  每个动作在 09 中有对应 animation-sheet 编号，本页只做索引。

### 7. 行为/AI 规格（敌人与功能性 NPC 必写）

- **感知模型**：视觉（距离/FOV/遮挡检查）、听觉（噪声半径引用 04）、嗅觉/其他；感知条积累与衰减速率（秒）。
- **状态机/行为树**（Mermaid）：巡逻→疑惑→搜索→追击→攻击→失去目标→返回，逐状态写进入条件、行为、时长、退出条件。
- 关键数值：移动速度（m/s，与玩家对比）、攻击距离/前摇/伤害/冷却、视野丢失后搜索时长、被关门阻挡的行为。
- 追击者专用：与玩家的**速度差设计**（通常慢于冲刺玩家但不会被甩脱，制造节奏而非必败）、破墙/绕行规则、是否会放弃。
- NPC：日程/站位、对话触发条件、被攻击/被偷时的反应、与其他 AI 的冲突处理。

### 8. 数值（引用 04，给本角色的具体值）

HP/伤害/硬直/韧性/弱点倍率/掉落/资源。写**预期战斗时长**（如 35-45s）并说明设计意图。

### 9. 声音需求（引用 10）

- 嗓音设定（性别、年龄、音色、说话方式）、脚步材质表、呼吸/喘息规则、非语义语音（受击/死亡/发力/警觉）数量、主题动机（leitmotif）。

### 10. 交付与验收

- 模型/贴图/动画/音频/AI 配置清单逐项对应文件命名（如 `SK_EN_Stitcher_01`、`AN_EN_Stitcher_Patrol_01`）。
- 测试用例：每个 AI 状态至少 1 个触发测试；玩家卡视野/绕圈/蹲伏/关灯等边界行为各 1 条。

## 完成定义

- [ ] 定位与情绪手段明确，与剧情弧光对齐
- [ ] 三视图/细节/表情概念图需求列全
- [ ] 面数/骨骼/贴图/LOD/表情数值符合 08 与 11 预算
- [ ] 动作清单逐条映射到 09 动画单页
- [ ] 敌人 AI 有感知模型+状态机+逐状态量化值+速度差设计
- [ ] 数值含预期战斗时长
- [ ] 声音需求含嗓音/脚步/非语义语音
- [ ] 每个状态与边界行为有测试用例
