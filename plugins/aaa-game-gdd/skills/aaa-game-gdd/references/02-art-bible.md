# 02 美术圣经（Art Bible）

## 解决什么问题

保证 100 个场景、500 个道具、3 个外包做出来像同一个游戏。美术圣经是所有视觉决策的最高法，回答「我们的游戏长什么样、为什么、禁忌是什么」。所有建模/场景/UI/特效单页都必须引用它。

## 何时写

概念末期开始，垂直切片期锁定主体；它是活文档，但视觉支柱与色板锁定后不可大改。

## 章节结构与写法

### 1. 视觉支柱（3-5 条，从核心支柱推导）

每条 = 关键词 + 解释 + 对画面的硬性约束。
例：「潮湿的腐败感」→ 所有表面带湿润反射或污渍，禁止干燥洁净的材质；「90 年代胶片质感」→ 颗粒、偏色、低饱和，禁止干净数码感。

### 2. 风格参照板（Moodboard）

- 收集 3 类参考并分别标注**学什么**：真实参考（照片/实地）、游戏参考、影视/绘画参考。
- 每个参考写清「借鉴点」：构图？色调？材质？光影？禁止只贴图不写字。
- 明确**反向参考**：我们不像什么（如「不要《堡垒之夜》的卡通高饱和」）。

### 3. 形状语言（Shape Language）

- 用方圆三角定义整体气质：威胁物=尖锐三角/不规则；安全区=圆角；机构=冰冷矩形。
- 角色与环境的比例规则（写实 7.5 头身？风格化 6 头身？），主角/敌人/普通 NPC 的剪影对比规则。
- **剪影测试要求**：所有主要角色与关键道具纯黑剪影必须可辨认。

### 4. 色彩规范

- 主色/辅色/点缀色，给出 HEX 与用途、面积比例（如主 70% / 辅 25% / 点缀 5%）。
- 情绪色表：安全/危险/解谜/回忆各用什么色，危险提示色全局唯一（如只允许红色用于威胁）。
- **色彩脚本（Color Script）**：按章节/关卡画一张色块缩略图序列，定义情绪起伏与色彩推进，关卡场景必须与之一致。
- 对比度与可读性规则：可交互物与背景的明度/色相差阈值（经验值：明度差 ≥ 30% 或色相差 ≥ 30°），关键路径引导用色温/亮度。

### 5. 材质与表面语言

- 列出材质库白名单：墙面、金属、木材、布料、皮肤的做旧规则（破损程度、污渍层、粗糙度区间）。
- PBR 参数约定：金属度/粗糙度的典型取值区间；水渍、血迹、灰尘的使用密度标准。
- 贴图统一规范：是否使用高度图、ORM/RMA 通道打包方式（与 11 技术文档对齐）。

### 6. 光照与氛围

- 全局基调：主光源类型（冷白日光灯/暖钨丝灯/自然光）、色温值范围（K）、阴影硬度、雾的使用规则。
- 每类场景的光照配方：环境光强度区间、关键光、补光、体积光、雾浓度；夜间/日间/应急状态的切换规则。
- 曝光与后处理：是否用泛光（Bloom 阈值与强度上限）、色彩映射、颗粒、暗角、色差；**3A 雷区：过度 Bloom/泛光/景深会显廉价，必须给上限**。

### 7. 构图与镜头语言

- 镜头：FOV（第一人称参考 70-80°，第三人称 35-50°）、镜头呼吸、手持晃动幅度、奔跑 FOV 拉伸量。
- 场景构图规则：引导线、门框构图、地标锚点间隔（玩家每走多远必须看到一个辨识度地标）。
- 可读性三层：远景地标剪影 → 中景路径引导 → 近景可交互物高光，逐层写明手法。

### 8. 角色/怪物/道具/UI 视觉规则（索引到各规格文档）

- 角色比例、服装年代、破损规则、面部风格化程度（详见 07）。
- 怪物设计原则：恐怖来源（未知/畸变/拟人崩坏）、露出频率（少即是多，写每章最大正面接触时长）。
- UI 风格：是否 diegetic（世界内）、字体气质、图标风格（详见 06）。

### 9. 禁忌清单（DO NOT）

明确列出一切禁止项，例如：禁止饱和渐变、禁止塑料感皮肤、禁止对称完美的怪物脸、禁止现代洁净感、禁止 UI 用霓虹紫。每条禁忌最好附一张反面参考图。

### 10. 风格一致性审查方法

- 出图后用「缩到 256px 仍能读出层次」「灰度截图仍可读路径」「与色彩脚本并排不违和」三招自检。
- 每张概念图/白模评审时对照视觉支柱逐条打勾，不过即返工。

## 完成定义

- [ ] 视觉支柱 3-5 条且每条可约束具体制作
- [ ] 参考板每图带「学什么」标注，且有反向参考
- [ ] 色板有 HEX、面积比例、情绪色表、章节色彩脚本
- [ ] 形状语言、比例、剪影测试规则明确
- [ ] 光照/后处理给出参数区间与上限
- [ ] 禁忌清单可执行，新人看了不会做跑偏
- [ ] 垂直切片场景通过三招自检
