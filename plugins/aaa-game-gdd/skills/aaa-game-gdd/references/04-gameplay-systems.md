# 04 主线玩法与系统设计

## 解决什么问题

把「好玩」拆成可程序实现、可数值平衡、可测试的系统规格。每个系统一张 system-sheet，核心文档只放：核心循环、系统清单、跨系统规则、数值总表。

## 何时写

概念期写核心循环与 1-2 个核心系统骨架（用于灰盒原型）；垂直切片期锁定所有核心系统；量产期补齐衍生系统。

## 核心文档章节

### 1. 核心循环（3 层）

- 即时循环（秒级）：如「移动→屏息探听→躲避→拾取」，每环的输入、反馈、奖励。
- 关卡循环（分钟级）：探索→遭遇/解谜→补给→新区域。
- 元循环（小时级）：找回器官→解锁新能力→医院深层区域→真相。
- 每层用 Mermaid 画闭环，标注**玩家为什么愿意再转一圈**（新信息/新能力/新威胁/新奖励）。

### 2. 系统清单（全游戏的系统目录）

| 编号 | 系统 | 支柱归属 | 优先级（Must/Should/Could） | 状态 | 单页 |
|---|---|---|---|---|---|
| SYS_01 | 移动与体力 | 支柱1 | Must | 已锁定 | systems/SYS_01... |

砍内容时先砍 Should/Could；Must 与核心支柱直接对应。

### 3. 系统单页（system-sheet）写法（每个系统必答）

1. **目的与玩家幻想**：解决什么体验，支撑哪条支柱。
2. **输入 → 输出**：玩家操作清单（按键引用 06），系统输出（状态变化/反馈/数值变化）。
3. **规则与流程**：Mermaid 状态机/流程图；每个状态的进入退出条件。
4. **参数表**（全部量化）：字段名、类型、默认值、最小值-最大值、调参说明。例：

| 参数 | 值 | 说明 |
|---|---|---|
| 屏息最大时长 | 8s | 初始，升级后 12s |
| 屏息恢复速度 | 3s 回满 | 站立静止 |
| 移动噪声半径 | 蹲 3m / 走 7m / 跑 14m | 敌人感知用，见 SYS_敌人AI |

5. **边界与异常**：死亡时该系统怎样？存档读档？暂停？中断过场？物品栏满？（3A 与业余差距全在边界处理）
6. **系统交互**：与哪些系统互相调用，接口事件名（如 `OnNoiseEmitted(radius)`）。
7. **存档字段**：哪些状态需要持久化，字段名与类型。
8. **验收标准**：可执行的测试用例（如「蹲伏经过 8m 外敌人，敌人感知条不增长」）。

### 4. 战斗系统（有战斗时必写）

- **攻击数据模型**：每把武器/招式一张表：前摇帧、判定帧（命中窗口起讫帧）、后摇帧、可取消窗口（帧）、伤害、削韧、冲击力、硬直、体力消耗、连段衔接窗口。所有帧数以 60fps 标注（帧数+秒数双写）。
- **命中与判定**：判定形状（盒/球/胶囊）、友伤、多目标、部位判定（头/身/腿倍率）、锁定规则。
- **受击反馈模型**：命中停顿（hitstop 帧数，轻击 40-80ms/重击 100-160ms）、震屏幅度、粒子、音效、手柄震动强度、伤害数字、相机冲击方向——逐个给值。
- **敌人/玩家死亡规则**：死亡镜头、死亡检查点、资源损失。
- **难度档位**：至少 3 档，列出每档变化的参数（敌人 HP/伤害/感知、玩家资源、提示频率），剧情难度必须存在（参考 3A 惯例）。

### 5. 经济与资源（任何有资源的游戏都要做）

- **来源/去处表（Source & Sink）**：每种资源（弹药/绷带/电池/货币）的获取速率、消耗出口、持有上限。
- 按关卡做**资源压力模拟**：玩家进入 LV_03 预计持有 X，关卡消耗 Y，补给 Z，确保既不富余到无压力也不卡死。
- 稀缺感是设计出来的：写出每类资源的「期望玩家行为」（如电池稀缺→选择性使用声音探测）。

### 6. 成长与解锁

- 能力/升级树总表：名称、效果（量化）、解锁位置、是否可错过、对后续关卡的影响。
- 反向校验：列出每关「必须拥有的能力」，确保没有能力缺口导致死局。

### 7. 游戏手感（Game Feel / Juice）总表（3A 标配，跨系统）

逐项决定做/不做并给参数：输入缓冲（如 150ms）、土狼时间（平台跳跃，100ms）、预输入、跳跃/闪避手感、命中停顿、震屏、粒子、相机反馈、手柄震动、自适应扳机、动作的预备-发生-余响三拍、脚步声材质反馈、UI 按下音效、命中确认的音画同步（误差 <1 帧）。规则：**每个玩家动作都必须在 100ms 内得到视听触至少一种反馈**。

### 8. 数值管理方式

- 全部数值进表（CSV/电子表格→导出 JSON/ ScriptableObject），禁止散落在代码里。
- 数值表随单页一起交付，字段含：参数名、当前值、来源公式、设计意图、上次调整记录。

## 完成定义

- [ ] 三层循环图闭环，每层标注再玩动机
- [ ] 系统清单含优先级，每个 Must 系统对应一条支柱
- [ ] 每个系统单页含：状态机、量化参数表、边界异常、存档字段、验收测试
- [ ] 战斗数据逐帧量化，反馈（hitstop/震屏/震动/音效）全部给值
- [ ] 资源 Source/Sink 表 + 逐关资源压力模拟
- [ ] 成长能力无死局缺口
- [ ] 手感清单逐项决策，100ms 反馈原则无死角
- [ ] 全部数值可在表中调整，无硬编码
