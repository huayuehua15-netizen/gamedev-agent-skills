# 10 音频设计

## 解决什么问题

音频是恐怖/沉浸游戏 50% 的体验，也是最常被推迟到最后的部分。本篇把音乐、音效、配音、动态音频、混音总线全部纳入资产清单与触发矩阵，让音频工程师在量产前就知道要做什么、在哪触发、什么规格。

## 何时写

垂直切片期定总线、音频体系与 1 个场景的完整音频样板；量产前按场景/系统单完成全量清单。

## 章节结构

### 1. 音频支柱与风格

- 从美术/叙事支柱推导声音风格（如「有机、潮湿、不协和」「以静衬响」）。
- 音乐语言：配器、调性/无调性、是否使用旋律（恐怖游戏常弱化旋律、强调音色与静默）。
- 参考曲目（游戏/影视 OST），标注学什么。

### 2. 总线（Bus）与混音标准

- 总线结构：Master / Music / SFX / Voice / UI / Ambience，各总线可独立调节（对应设置菜单四个音量滑块）。
- 响度参考：Master 目标 -23 LUFS（平台/电视标准）作为基准；对白清晰度优先（对白出现时音乐/环境自动 duck，侧链压缩量写具体，如 -6dB）；峰值不超过 -1 dBFS。
- 单音素材规范：WAV 48kHz，音效单声道（定位用）、环境/音乐立体声；采样位深 24bit 制作。
- 全平台：移动端/Deck 扬声器与耳机分别检查，保证小声量段（低语）可听。

### 3. 音乐设计

- 曲目清单：编号 `AU_MUS_`、名称、使用场景/关卡、时长、是否循环、循环点、情绪。
- 动态音乐系统（3A 标配，按项目能力选）：
  - 水平重混音（分段切换：探索→紧张→战斗）；垂直重混音（同段落逐层叠加 stem）。
  - 每个状态的进入/退出条件、过渡时长（秒）、stem 分层（基础层/鼓点层/紧张层）。
- 战斗音乐的脱战冷却规则；安全区主题动机；角色 leitmotif（与 07 角色声音需求对齐）。

### 4. 音效清单（SFX）

按类编号：

| 类别 | 编号前缀 | 内容示例 |
|---|---|---|
| 交互 | `AU_UI_` | 按钮、菜单、拾取、确认/失败/警告 |
| 角色 | `AU_PL_`/`AU_EN_` | 脚步（按材质×速度）、喘息、攻击、受击、死亡 |
| 物体 | `AU_PR_` | 门、柜、金属碰撞、破碎、道具通电 |
| 环境 | `AU_AMB_` | 底噪、风声、管道滴水、远处异响（随机触发） |
| 特殊 | `AU_SC_` | 惊吓 sting、脚本事件、怪物主题音 |

- 每个音效应有 3-5 个随机变体（避免重复疲劳），脚步按表面材质（木/金属/瓷砖/地毯/水）× 速度 × 鞋型矩阵。
- 变体命名：`AU_PR_DoorCreak_01.wav … _05.wav`。

### 5. 声学系统（空间音频）

- 传播：遮挡/衰减曲线、穿墙 muffled（低通）、混响区（走廊/房间/室外/地下室，标混响参数区间）。
- 恐怖游戏专用：声源位置是玩法信息时，必须有可靠的双声道/HRTF 定位；不可定位的氛围声与可定位的威胁声分开设计。
- 声音作为机制：敌人听觉（引用 04 噪声半径）、玩家制造噪声（移动/碰撞/推物），每个交互动作的噪声 dB/半径表。

### 6. 配音（VO）

- 从 05 台词单页派生配音单：ID、角色、语种、情绪、时长、录音规范（48kHz、干声、房间音一致）、非语义语音（grunt 表）数量。
- 命名：`VO_角色_场景_序号`；交付时干声与处理后版本分开。
- 本地化配音策略：首发哪些语种配音，其余语种至少字幕（写进 12 本地化表）。

### 7. 触发矩阵（派工与集成依据）

逐场景/逐系统列出触发：音频 ID｜触发对象（场景/动作/事件）｜触发条件｜2D/3D｜衰减距离｜同时播放限制｜优先级（高优先级抢占规则，如惊吓 sting 抢占环境声）。

### 8. 技术与性能

- 同时发声数上限（PC 约 24-48 voice，Deck 取低端），优先级与虚拟声（virtual voice）规则。
- 音频压缩：短音效 PCM/ADPCM，长音乐与环境流压缩（如 Vorbis，质量档），单文件大小与内存预算（引用 11）。
- 内存：常驻音频（UI/脚步）与按需加载音频（场景/过场）划分。

- [ ] 音效清单覆盖全部交互、材质脚步、环境与脚本事件，变体 3-5 个
