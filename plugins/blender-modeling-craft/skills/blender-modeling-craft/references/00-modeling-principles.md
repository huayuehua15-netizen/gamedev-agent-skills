# 00 · 建模原则：为什么 AI 做的模型一眼烂，以及怎么不烂

> 解决什么问题：大模型用 bpy 做出来的模型普遍"廉价感、方块味、比例怪、塑料感"。这篇讲清楚根因与每次开工前的判断。

## 1. 先判断：该不该自己做

按顺序问，命中前面就停：

1. 素材库有没有现成的？（走 `unity-blender-mcp` 的素材优先决策树，MCP 内置 → CC0 → 市场 → 国内站 → Mixamo → AI 生成）
2. 角色/带动作的生物？**默认 Mixamo + Quaternius 角色包**，自建角色绑定是专业 TD 活，AI 基本做不好。
3. 单个明确物体（一把椅子、一个箱子、特定道具）且素材库风格不匹配？→ 本技能自建。
4. 要改素材（加破损、改结构、减面、重拓扑）？→ 本技能，从"审计"开始。
5. 整场景/地形？→ 永远用模块化拼装：自建若干可复用模块 + 素材库，不要手搓整个场景。

**自建的正确对象**：项目专属的硬表面道具（武器、家具、装置、建筑模块）、风格化的岩石/植被模块、AI 生成件的重拓扑修复。

## 2. AI 烂模的 9 个特征（自查清单，命中即修）

1. **方块堆砌**：物体由几个互相穿插的立方体组成，没有融合、没有过渡、没有倒角。
2. **锐利边**：所有边都是数学直角，渲染时没有高光描边，像没渲染完的灰盒。
3. **比例错误**：门比人矮、椅子到腰、杯子比头大；没有真实尺寸概念。
4. **对称崩坏**：镜像没用 Clipping，中缝开裂或重复；左右细节不一致。
5. **正面建模**：只有正面能看，侧面和背面是空的、平的、或忘做。
6. **无厚度**：杯子、管子、门板是单片平面，侧看是纸片。
7. **布尔残留**：布尔后洞周围是 N-gon 烂面、阴影撕裂、法线翻转。
8. **材质塑料**：默认白灰 Principled、粗糙度 0.5 一刀切；没有灰尘/磨损/色差，像全新玩具。
9. **密度错配**：远看轮廓对了，近看没有细节层级（大形/中形/小形/表面细节至少三层）。

## 3. 七条手艺原则

### 3.1 比例先于一切
- 人对比例的敏感度远高于对细节：比例对了，白模都好看；比例错了，4K 贴图也救不回来。
- 真实尺寸是比例的锚：开工查 `assets/real-world-dimensions.csv`，场景里常驻一个 1.7m 人体标尺。
- 道具的"尺度感"由它与人手、人体的关系决定：手柄直径 30–40mm（握得下）、坐面高 450mm（小腿长）、桌面高 750mm（坐姿肘高）。

### 3.2 体量 → 结构 → 细节，不可跳级
- **大形（blockout）**：盒子、圆柱、球体，只做几何关系和剪影。
- **中形（structure）**：分件、连接、转折、厚度、倒角。
- **小形（detail）**：螺丝、接缝、卡扣、铆钉、破损。
- **表面（surface）**：材质、法线、粗糙度变化。
- 下一层不允许在上一层未确认前开始。blockout 阶段必须渲染一次让用户/自己确认比例。

### 3.3 剪影测试（Silhouette Test）
- 用纯黑材质 + 白底渲染一张纯剪影图。**只看轮廓，能不能认出是什么？** 这是枪械、椅子、载具、角色识别度的核心。
- 剪影靠"大形的外轮廓"，不是贴图。剪影糊了就改大形。

### 3.4 倒角法则（最重要的视觉细节）
- 现实中没有数学锐利边：机加工金属边有 0.2–1mm 倒角；木家具边有 2–5mm 圆角；塑料件有出模斜度和圆角。
- 倒角的作用：**让光线在边缘产生连续高光**，这是"品质感"最大的来源。
- 数值参考（物体真实尺度）：
  - 手持小物/武器：0.3–0.8mm
  - 家具/金属道具：1–3mm
  - 建筑/混凝土：5–20mm（常靠倒角贴图/法线）
- 段数：2 段（近景 3–4 段）；配合"硬化法线"或 Weighted Normal 修改器。
- 倒角不能乱倒：**卡线位置决定倒角宽度**，大面积不要有细分段，曲率要均匀。

### 3.5 非破坏式（Modifiers-First）
- 镜像（Mirror + Clipping）→ 实体化（Solidify）→ 倒角（Bevel, Angle 限制）→ 细分（Subdivision）→ 加权法线（Weighted Normal）。
- 改完再 Apply；Apply 前把高模复制一份命名 `_subd` 藏起来。
- 布尔用"布尔修改器 + 重拓扑"或 voxel remesh，不要直接留下布尔结果。

### 3.6 三层材质
- 颜色（Base Color）：大面积做轻微色差与旧化（顶点色或污渍遮罩）。
- 粗糙度（Roughness）：同一材质不同粗糙度——把手磨亮、凹处积灰、边缘掉漆。
- 法线/高度（Normal）：细分做不到的细节用烘焙法线 + 贴花（decal）表达。
- 不要用纯色：Base Color 至少加轻微随机变化（参考 04）。

### 3.7 三视角义务
- 每个物体都必须有"正面、侧面、背面"的完整设计。做的时候就把三个角度都渲染检查，禁止只建模一个机位。

## 4. 开工前的信息收集（一次问清，≤4 问）

1. 物体是什么、在游戏里怎么用（近景可交互/中景/远景）、放在什么场景。
2. 风格（写实/半写实/卡通）与目标面数预算（见 07）。
3. 有没有概念图/参考图；没有就先搜集（图片搜索、同类型游戏截图、实物照片），至少 front+side。
4. 是否需要可动部件/碰撞/破碎；要不要 LOD。

没有参考图时：**先搜图、先用参考图建 blockout，不要直接凭想象建。** 可以用图片生成工具生成正视图概念图，但必须标注为"概念参考"，尺寸仍以真实值为准。

## 5. 阶段产出与门禁

| 阶段 | 产出 | 门禁（不过不继续） |
|---|---|---|
| 参考 | REF_References 集合（front/side/top）、尺寸记录 | 参考图与真实尺寸齐全 |
| Blockout | REF 集合外的体量模型 + 人体标尺 | 4 角度渲染，比例经自己/用户确认 |
| 细化 | 分件完成、厚度、倒角、细节层级 | 剪影测试通过；6 个面都完整 |
| 拓扑/UV | 四边面网格、UV 展开、材质 | topology_audit 全绿 |
| QA | 剪影门禁 + 渲染人审记录 | 门禁 passed 且 06 的 rubric 达标 |
| 交接 | LOD + FBX + 命名 | Unity 导入无异常（对接 unity-blender-mcp） |
