# 04 · 游戏级拓扑、UV、烘焙与 PBR

> 这篇把模型"从形状变成游戏资产"：干净的拓扑、规范的 UV、可复用的 PBR 贴图。交付前必跑 `scripts/topology_audit.py`。

## 1. 拓扑规则（硬表面）

- **四边面为主**：占比 ≥ 95%。三角面允许但只放在：看不见的底面、平面内部、非变形区；禁止三角面出现在边缘和弯折处。
- **禁止 N-gon**：N-gon 在引擎里三角化结果不可控，会导致光照撕裂、烘焙穿帮、法线异常。
- **边流（Edge Flow）**：环线沿结构转折走（圆柱是环形 + 纵向、盒子是环绕边缘）；环线之间间距均匀。
- **极点（Pole）**：5 极/6 极可以，但放在平面内部、远离边缘和弯曲处；禁止 3 极以上极点出现在高对比曲面上。
- **密度分布**：细节处密（把手、接口、损伤），平面处疏；圆柱与平面融合处两边段数一致。
- **变形件（会动的）**：关节处环切线与旋转轴垂直；角色肘/膝/肩 6–8 圈环。
- **无脏数据**：无重复顶点（remove doubles，阈值 0.0002）、无松散点/面、无内反面、无非流形。
- **变换已应用**：所有对象 scale=(1,1,1)、rotation 归零；`topology_audit.py` 会报。

## 2. 面数预算（在预算内分配细节）

详见 `07-unity-handover.md` 的预算表。原则：先定总三角面，再按部件分配——大形占 70%，细节 30%；不要在不可见区域花面。

## 3. UV 展开规范

### 展开顺序
1. 接缝（Seam）：缝藏在不显眼处（背面、底面、部件交界），保持每个岛是规整的矩形/条带。
2. 硬表面：Angle 30° 自动选锐边 Mark Seam → Unwrap；或 Smart UV Project（angle 66°，island margin 0.003）。
3. 展开后摆直岛（对齐方向）、规整排列、最大化利用空间。

### 硬性要求
- 每个面都必须在 0–1 UV 空间内（除了用 atlas 平铺时），无重叠（除非是明确要镜像复用的对称件）。
- 对称件可镜像一半 UV（省一半空间），但要接受无法左右差异化贴图。
- 岛的方向统一（木纹、拉丝、布料纹理方向一致）。
- 接缝两侧 texel 密度一致，避免贴图缩放不一致。
- 硬表面法线烘焙：岛边缘留 8–16px padding（4096 下约 16px，2048 下 8px）。

### Texel Density（像素密度）

按"玩家最近可观察距离"定：

| 距离 | 场景 | 1m 表面需要的纹理像素 | 常用分辨率 |
|---|---|---|---|
| 近距离可交互（武器/手持） | 第一人称 | 2048–2560 px/m | 2048 给 ~1m 物体；1024 给 0.5m |
| 近景道具/家具 | 1–3m | 1024–1280 px/m | 1024–2048 |
| 中景场景模块 | 3–8m | 512–768 px/m | 1024 共享 atlas |
| 远景/背景 | >8m | 256–384 px/m | 512 atlas |
| 移动端/低配 | 全局 | 256–512 px/m | 减半 |

> 这张表是**全项目 texel density 的唯一口径**（GDD 侧 `08-prop-modeling.md` 引用同一张表，不再单独给"全局 1024px/m"这种与之冲突的数字）。
> 1024px/m 意味着 1 米的面在 UV 里占满 1024 像素；0.5m 的椅子若给 1024 图，密度会翻倍到 2048px/m，所以小件要么减图、要么提分辨率。同一场景内密度保持一致，不要一个 2048 一个 256。

### 检查方法
- Blender UV 编辑器中用 Checker Map（编号格/数字格）显示密度，全岛格子大小一致为合格。
- 拉伸检查：Stretch 着色视图（蓝色合格，红色拉伸）。

## 4. 烘焙：高模细节搬到低模

需要的贴图（URP）：
- **Normal（法线）**：高模凹凸到低模；存 Non-Color。
- **AO（环境光遮蔽，可并入 AO 通道或单独乘底色）**：缝隙脏污基础。
- **Curvature（曲率，用于边缘磨损）**：生成遮罩给掉漆/磨损效果用。
- **Base Color**：纯色或绘制的颜色层；贴图细节（污渍、掉漆、色差）画在这。
- **RMA**（R=**Roughness**、G=**Metallic**、B=**AO**）打包；Non-Color。

> 三种打包约定互不相同，**全项目只能选一种**，并在技术文档里写死：
> - **ORM**（glTF/UE 标准）：R=AO、G=Roughness、B=Metallic；
> - **RMA**：R=Roughness、G=Metallic、B=AO（与 ORM 的 R/B 对调）；
> - **Unity HDRP Mask Map**：R=Metallic、G=AO、B=Detail Mask、A=Smoothness。
>
> 上面 08 号资产规格文档与本表必须一致；改口径时两处一起改。

烘焙要点：
1. 低模 UV 完成、岛 padding 足够；高模在低模外侧 0–0.02m。
2. Selected to Active；Ray Distance 用 cage（建一个略微放大的低模副本当 cage），接缝处不漏。
3. 法线用 OpenGL 格式（Blender 导出为 Unity 默认；Unity 使用 OpenGL normals，若用 DirectX 要在 Unity 翻转绿色通道）。
4. 先低分辨率（512）试烘，无问题再上最终分辨率。

## 5. PBR 材质（3A 质感的关键在粗糙度分层）

- **粗糙度是质感的主角**：同一物体上粗糙度必须有空间变化：
  - 金属：新件 0.3–0.5；常被手摸的把手/边缘 0.15–0.25（磨亮）；凹处/脏污 0.7–0.9。
  - 木材：0.45–0.7（漆面更低，0.2–0.35）；磨损处露出木头粗糙度上升。
  - 塑料：0.55–0.75；橡胶：0.8–0.95。
- **金属度尽量二元**：0 或 1，中间值（0.4）只用于脏污/锈迹过渡。
- **Base Color 不要纯色**：大面加 ±5% 的色差、污渍、边缘掉漆露出底层色；颜色整体偏灰（不要过度饱和），让粗糙度和光照讲故事。
- **贴花（Decal）**：标签、划痕、漏水痕、编号字用独立透明贴图贴在物体表面，比堆几何省钱。
- **法线强度克制**：Normal Map Strength 0.5–1，别让法线把平面扭曲成塑料感。

## 6. 材质节点规范（与 Unity URP 对应）

- 输出与命名：`T_<Asset>_BC`、`T_<Asset>_N`、`T_<Asset>_RMA`（或 `_M`）；颜色图 sRGB，N/RMA 为 Non-Color。
- Blender 节点：BC 接 Base Color；N 经 Normal Map 节点接 Normal；RMA 经 Separate RGB：R→Metallic、G→Roughness、B→AO（AO 乘 Base Color 或用 Mix 相乘）。
- 交接给 Unity 的是贴图文件（PNG/TGA）+ 材质规格（金属度/粗糙度数值），不依赖 Blender 的 Principled 节点直接迁移；导入后按 URP 重建（unity-blender-mcp 有 Postprocessor 自动处理后缀）。
