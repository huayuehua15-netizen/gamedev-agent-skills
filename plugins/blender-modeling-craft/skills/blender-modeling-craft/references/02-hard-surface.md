# 02 · 硬表面建模工作流（道具 / 家具 / 武器 / 建筑 / 载具）

> 硬表面 = 人造的、有明确平面和转角的物体。AI 自建的主战场。核心方法：盒建模（Box Modeling）+ 卡线倒角 + 非破坏修改器。

## 通用 7 步（任何硬表面资产都走）

1. **参考图 + 尺寸**：front/side/top 参考图导入 REF_References；查 `assets/real-world-dimensions.csv`；建人体标尺。
2. **Blockout**：用 `add_dim_box/cylinder` 把物体拆成 3–8 个主要体量（机匣、枪管、握把、枪托…），不做任何倒角细节。这一步就渲染与参考图叠对。
3. **分件**：每个体量是独立对象，命名 `SM_<Asset>_<Part>`（如 `SM_Rifle_Body`）。真实物件是分件的——分件接缝本身就是细节。
4. **厚度与结构**：实心件用盒子；薄壁件（柜子、门板、管子）加 Solidify（offset=-1 向内，厚度 2–10mm）。
5. **倒角/卡线**：所有硬边 Bevel（0.5–3mm，2–3 段，Angle 30°，harden_normals）+ Weighted Normal；大平面保持干净，曲率变化集中在边缘。
6. **中细节**：螺丝、接缝线、卡扣、铆钉、通风口、文字铭牌——用独立小物件或贴图表达，不要堆布尔。
7. **低模/拓扑 → UV → 材质 → QA 渲染**（见 04、06）。

## 分类要点

### 家具（椅/桌/柜/床）
- 先做**人体关系**：坐面 450mm、桌面 750mm、扶手 600–700mm、靠背 850–950mm。
- 实木家具有较大圆角（2–5mm 甚至 10mm），金属管家具倒角 1–2mm。
- 软包（沙发/床垫）用细分曲面 + 略微鼓起的坐垫，不要用尖角盒子。
- 四条腿永远先做一条再镜像，用 Mirror + Clipping。

### 手持道具（杯子/瓶子/工具/手电筒）
- 以**人手尺度**为锚：直径 30–90mm，握柄直径 30–40mm。
- 轴对称物体用圆柱 + 环切缩放（profile）做，不要纵向堆盒子。
- 空心容器先做外形，再 Solidify 或内缩面做内腔。
- 杯子把手：画曲线（Bezier）→ 转网格 → 实体化（或曲线 Bevel Depth 12–15mm）。

### 武器（刀剑/枪械/棍棒）
- **刀剑**：剑身是细长盒（刃厚 3–6mm，向刃口收薄），刃口用单一窄倒角/卡线；护手、握柄、配重球分件做；不要让剑刃有宽度均匀的"尺子感"。
- **枪械**：机匣是主体（盒），枪管是圆柱（用 profile 做粗细变化），护木、握把、枪托、弹匣各自独立；导轨用矩形截面沿长度阵列；刻字/标识用贴图。
- 金属件倒角 0.3–0.8mm，高金属度（0.8–1.0）+ 中低粗糙度（0.25–0.45，磨损处更低）；握把用深色非金属（粗糙度 0.7–0.9）。
- 比例以真实型号为准（AK 全长约 870–950mm，手枪 180–220mm）。

### 建筑与场景模块（门/墙/楼梯/地板模块）
- 模块化思想：定网格（grid 通常 1m/2m/4m），每个模块尺寸是网格的整数倍，边缘可拼接。
- 门框、窗框是独立件；墙板是带厚度的盒子（Solidify 80–200mm），不是平面。
- 踢脚、线脚、腰线用单独的长条件，不要在墙上挤出。
- 铰链、门锁、开关、插座是近景必须的小细节（远景用贴图）。
- 标准门洞 2.05–2.15m × 0.8–0.9m；层高 2.7m 起。

### 载具（车/船的简化件）
- 大形拆 5 块：底盘、车身壳体、座舱（玻璃）、轮/履带、附件。
- 车壳用盒子 blockout → 大斜角（用整面卡线或 Edge Crease）→ 细分；不要在大面上乱加环切。
- 轮子是直径 600–700mm 的圆柱，轴向沿车宽；胎面花纹用贴图，不建模。
- 挡风玻璃必须是独立材质（透明/反射），与车身分件。
- 载具是高难度资产，先评估素材库与 AI 生成，自建通常只做风格化/低面数车型。

## 布尔的正确用法（避免烂面）

- 布尔只用一次成型：把所有要挖的形状合并成一个 cutter（Join 多个 cutter），一次 Difference，减少交叠。
- solver 用 EXACT；应用后立即：remove_doubles → 重算法线 → 检查 N-gon。
- 洞周围的 N-gon 必须重连为四边面（拓扑沿洞口走环形线），并给洞口补倒角。
- 复杂有机状缺口（破损、岩石）不用布尔，用 voxel remesh。

## 细分曲面（Subdivision）卡线规则

| 结构 | 卡线方式 |
|---|---|
| 大平面保持平整 | 平面内不留多余环切线；轮廓线靠边缘 |
| 想要 90° 硬边 | 边缘两侧各一条环线，间距 = 圆角宽度 |
| 想要柔和大圆角 | 卡线离边缘远，或直接用 Bevel 修改器 |
| 圆柱与平面融合 | 走一圈环形线，点数一致，避免扭曲 |

## 细节层级与密度

- **不做均匀的密**：细节集中在玩家会盯的地方（把手、按钮、交界面、损伤处）；远离视线的底面/背面简化。
- 小细节优先级：分件接缝 > 边缘倒角 > 螺丝/铆钉 > 表面纹理（贴图）。
- 一个 3000 面的近景道具，合理的中细节约 20–60 个小特征，而不是一片光面。

## 禁止事项

- 禁止用多个互相穿插的盒子当"做完了"（穿插必须融合或有真实的连接关系）。
- 禁止大面积平面不卡线直接细分（会鼓）。
- 禁止 Apply 镜像后不对称修改；需要非对称细节时，先 Apply 再做。
- 禁止无意义的高段数圆柱（远景 8–12 边，中景 16–24，近景 24–32，够用即止）。
