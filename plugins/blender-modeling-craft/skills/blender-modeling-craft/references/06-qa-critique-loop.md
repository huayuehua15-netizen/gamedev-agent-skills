# 06 · 渲染自检与迭代闭环（模型质量的真正保障）

> 模型不是"做完"的，是"渲染出来反复挑毛病、改完的"。
> 但顺序必须是：**先过机器门禁（剪影 IoU），再过人眼（rubric）**。
> 模型自评那一轮不算证据——多数运行环境里它根本看不到渲染图。

## 1. 固定质检流程

用 `scripts/qa_render.py` 出固定 4 角度（35/125/215/305° 方位角、22° 俯角），中性灰背景、三点布光、地面投影：

```bash
# 单件对象
blender --background --python scripts/qa_render.py -- asset.blend --target SM_Chair_Seat --outdir C:/tmp/qa_r1
# 整个资产集合（推荐）
blender --background --python scripts/qa_render.py -- asset.blend --collection Chair --outdir C:/tmp/qa_r1
```

MCP 环境用 `get_viewport_screenshot` 时也要覆盖同等角度（正前 3/4、正侧、背 3/4、背面），并在实体着色（非线框）下查看。

### 1.1 先跑剪影门禁（机器判定，不看"感觉"）

造型与比例是唯一能数字化的部分。门禁不过，后面的 rubric 不用做：

```bash
# blockout 阶段：阈值宽，用来挡住"大形就错了"
blender --background --python scripts/qa_render.py -- asset.blend --gate \
    --ref-front refs/front.png --ref-side refs/side.png \
    --stage blockout --outdir C:/tmp/qa_gate

# 成品阶段：阈值严
blender --background --python scripts/qa_render.py -- asset.blend --gate \
    --ref-front refs/front.png --stage final --outdir C:/tmp/qa_gate
```

- 退出码：`0` 通过 / `1` 不通过 / `2` 参数或参考图有问题。**不通过就禁止导出。**
- 报告写在 `qa_gate.json`：每个视角的 `iou`、`aspect_error`、失败原因。
- 参考图必须是正视图 / 侧视图，或手工描好的轮廓；带透视的照片不能直接比。
- 门禁只看外轮廓与比例，倒角、材质、旧化仍然只能靠 rubric 和人眼。
- 判定是平移不变的：模型在画面里偏左偏右不影响分数，只有形状和宽高比算数。

## 2. 每轮自评 Rubric（10 维，逐维判 0/1，必须有证据）

| # | 维度 | 怎么看 | 合格标准 |
|---|---|---|---|
| 1 | **剪影识别** | 想象把模型纯黑，能认出是什么 | 轮廓清晰，无多余凸起，关键特征（椅背、枪管、把手）在外轮廓上可见 |
| 2 | **真实比例** | 与 1.7m 标尺、参考图同框 | 尺寸偏差 ≤15%，无"椅子到腰""杯子比头大" |
| 3 | **正面/侧面/背面完整** | 4 张图逐张看 | 没有"正面像、背面空"；侧面厚度合理 |
| 4 | **边缘倒角与高光** | 主光打在棱角上 | 每条硬边有连续细高光；没有数学锐利的黑边 |
| 5 | **分件与接缝** | 找真实物件的拼接位置 | 分件数与真实物件一致（椅子有拉档、油桶有箍、枪有导轨） |
| 6 | **厚度与落地** | 看侧/底，找薄片感 | 薄壁件有厚度；4 腿/底座落地无悬浮、无穿插 |
| 7 | **无穿插/破面** | 检查部件交叠处 | 没有穿模、没有悬空小面、布尔周围阴影正常 |
| 8 | **材质与粗糙度** | 看反光是否一致 | 同一材质有粗糙度变化；没有"统一塑料感"；金属/木头/塑料可区分 |
| 9 | **细节密度** | 近景图 | 有中细节（螺丝/接缝/磨损）；大面不光秃、细节不堆在一个地方 |
| 10 | **旧化/可信度** | 整体第一眼 | 不像全新玩具；有轻微色差/磨损/灰尘（写实风格） |

**自评方法**：每张图逐维过，命中 0 分就记录具体位置（"左后腿与地面间有 3cm 缝隙""桶身没有环筋"），禁止只写"还可以"。

## 3. 阶段、门禁与迭代

- **blockout 阶段**：只修比例、体量、缺失的大部件。跑 `--stage blockout`，IoU ≥0.70、宽高比误差 ≤10%。不过就不许细化。
- **结构阶段**：修倒角、分件、穿插、薄片、背面遗漏。
- **成品阶段**：UV 与材质完成后，跑 `--stage final`，IoU ≥0.85、宽高比误差 ≤5%；再按 rubric 人审粗糙度、色差、旧化、密度。

**门禁通过 + 人审 10 维通过，才允许导出。** 任何阶段发现比例问题，回 blockout 改大形，不要在错误的大形上糊细节。

## 4. 常见问题 → 修复对照表

| 渲染看到的问题 | 根因 | 修复 |
|---|---|---|
| 边缘是纯黑/死白的锐线，没有渐变 | 没倒角 | 全部硬边 Bevel 0.5–3mm + Weighted Normal |
| 整个模型像乐高/玩具 | 方块堆砌 + 全塑料材质 | 补真实分件；金属/木/塑料区分；粗糙度分层 |
| 椅子/桌子看起来"站不稳" | 腿没落地、拉档缺失、透视问题 | 对齐 z=0；补横撑；4 角度检查 |
| 模型特别小/特别大 | 没用米制、没有标尺 | ensure_units_metric；人体标尺旁重核 |
| 侧面看薄得像纸片 | 没 Solidify/没有厚度 | Solidify 向内加厚；金属件参考真实厚度 |
| 布尔孔洞周围阴影撕裂 | N-gon/法线乱 | 重连四边面、重算法线、洞口补倒角 |
| 表面是糊的一大片 | 细分后平面鼓、卡线错 | 平面内删多余环线；结构边缘补卡线 |
| 金属看起来像塑料 | 金属度低/粗糙度高/没有反射 | 金属度 0.8–1.0；粗糙度 0.2–0.5；加环境反射 |
| 木头看起来像塑料 | 无纹理/粗糙度单一 | 木纹贴图（方向沿构件）；粗糙度 0.45–0.65 |
| 模型"太干净" | 无任何旧化 | 边缘磨损（曲率遮罩）、凹处积灰、轻微色差 |
| 某些角度看像没做完 | 只做了正面 | 补背面、底面、侧面；4 角度逐张过 |
| 轮廓认不出是什么 | 大形不对 | 回 blockout，对照真实参考图改剪影 |
| 镜头里模型被裁切/太小 | 取景问题 | 用 qa_render 角点法（已含 22% 安全边距）；单资产用 --collection |

## 5. 人工/用户确认节点

- **blockout 是唯一必须人审的点**：门禁通过后，仍要发给用户确认"比例锁定"，再细化。
- 成品阶段渲染 4 张图 + `qa_gate.json` 一起作为交付证明，不要只给 .blend/.fbx。
- 近景可交互资产额外加一张"玩家距离视角"（第一人称 ~0.5–1.5m 高度的平视）。

## 6. 记录要求

每次 QA 保存渲染目录（`qa_r1`/`qa_r2`/`qa_r3`），并在对话里列出：本轮发现问题清单 → 每项修复动作 → 下一轮验证结果。修不掉的问题明确标注（如"风格化选择，不修"），不要静默忽略。
